# Bank Product Framework

`product-framework.md` is the **generic coverage & product skeleton** (client geography,
industry verticals, product lines, policy-flag structure) that gets injected into the
Synthesize & Review agent at run time — see [knowledge-injection.md](knowledge-injection.md)
for the injection mechanism.

In production this skeleton was instantiated for a specific bank with its own disclosure
facts and policy flags. That bank-specific instance is an engagement artefact and is **not
included in this public repository** — the generic skeleton is everything the pipeline
architecture needs to be understood and reproduced.
